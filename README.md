📦 Установка и запуск проекта

Клонируйте репозиторий:

git clone https://github.com/DonPabla/gamelab-site.git


Перейдите в папку проекта:

cd gamelab-site


Установите зависимости:

npm install


Запустите проект:

npm run dev
